PRISM RUSH — a bright, colorful 2D arcade game for Roblox. Mine crystals to charge the portal, blast chaser drones and splitters, dash through danger, and fight through 4 vivid zones (Ember Grotto, Tide Cavern, Bloom Hollow, Prism Core) to restore the Prism. Built with Rojo + Luau; every screen is drawn with GUI frames, gradients and glows.

## Run it

```sh
rojo build default.project.json --output game.rbxl
```

Then open `game.rbxl` in Roblox Studio and press Play. Controls: WASD/arrows to move, Space to dash, hold E near a crystal to mine it, click to shoot.
